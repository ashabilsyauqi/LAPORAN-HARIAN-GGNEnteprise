Pertanyaan Umum (FAQ)

Format file desain apa saja yang diterima? ▼

Kami menerima file dalam format PDF (direkomendasikan vector/high-res), TIFF (LZW compressed), Adobe Illustrator (.AI), Photoshop (.PSD), JPG dan PNG dengan resolusi minimal 150-300 DPI dan color profile CMYK untuk akurasi warna terbaik.

Berapa lama proses cetak spanduk dan stiker? ▼

Untuk pesanan reguler, spanduk flexi dan stiker label A3+ dapat selesai dalam 3-6 jam setelah file terkonfirmasi siap cetak (ready to print). Anda juga dapat memilih opsi cetak kilat Same Day.

Apakah ada bantuan layout atau revisi jika belum ada file desain? ▼

Ya! Tim preflight dan setting layout kami siap membantu penyesuaian ukuran, penambahan mata ayam, bleeding potong, atau setting stiker secara gratis untuk pesanan Anda.

Bagaimana prosedur pengiriman luar kota? ▼

Pesanan luar kota digulung rapi dan dimasukkan ke dalam selongsong pipa kardus tebal (hard cone tube) lalu dilapisi bubble wrap anti air, dikirim via JNE Trucking (JTR), SiCepat Cargo, atau kurir pilihan Anda.
